# Allo AI 🤖

Allo AI is a Python chatbot project with two models:

## Allo 1.0 Fast
- Lightweight chatbot
- Quick responses
- Good for testing and learning

## Allo 1.0 Pro
- More advanced chatbot logic
- Larger response system
- Ready for future AI model upgrades

## Features
- Python CLI chatbot
- Simple AI architecture
- Training data support
- Easy to customize

## Setup

```bash
python3 -m venv allo_env
source allo_env/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python allo_fast.py
```

or

```bash
python allo_pro.py
```

## Files

```
allo_fast.py      # Allo 1.0 Fast
allo_pro.py       # Allo 1.0 Pro
train_data.json   # Training examples
requirements.txt  # Python packages
```
